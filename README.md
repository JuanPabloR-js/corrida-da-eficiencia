# A Corrida da Eficiência

Projeto da disciplina de Projeto e Análise de Algoritmos.

**Aluno:** Juan Pablo Rocha Hempel

## Objetivo

Comparar o desempenho de algoritmos de busca e ordenação em vetores de diferentes tamanhos.

## Algoritmos utilizados

- Busca Linear
- Busca Binária
- Selection Sort
- Merge Sort

## Arquivos

- Main.java: executa os testes.
- Metricas.java: registra tempo, comparações, trocas e movimentos.
- Buscas.java: implementa os algoritmos de busca.
- Ordenacao.java: implementa os algoritmos de ordenação.

## Como executar

Abra o projeto no IntelliJ com Java 21 e execute a classe Main.

Os resultados aparecem no console. Cada teste é executado quatro vezes, descartando a primeira execução e calculando a média das outras três.
